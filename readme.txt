弓道射法八節射形解析アプリ

＜本アプリの特徴・できること＞  

 １）動画ファイルの再生中、キーの押下操作によって、再生モードが変更できる

   再生の一時停止／再開、終了
   再生速度の変更（スロー再生、早送り）  
   画像（フレーム）のスキップ、巻き戻し 繰り返し再生  
   スクリーンへのグリッド表示  
   画像の部分拡大（ズームアップ。ただし画素は粗くなる）

 ２）動画ファイルをクリッピングして、別ファイルに保存できる

   ファイル保存したい矩形領域を、マウスでドラッグして指定（平面的なクリッピング）  
   2番目以降の矩形領域でモザイク表示を指定  
   別ファイルへの書き出し開始／停止をキー操作で指定（時間的なクリッピング）  
   停止・開始の繰り返しで、途中のフレームカットができる

 ３）動画ファイルの射形を解析して、骨格の動き、射法八節の動作状況を表示する

   骨格の動きをAI(YOLOモデル)で姿勢解析し、再生画面に表示  
   プログラムによるロジック解析および、AI(GRU)モデルで射法八節の動作状況を解析して再生画面に表示  
   解析結果のデータをファイルに保存、データベース（SQLite3）への登録  
   解析結果データのプロット表示  
   射形評価データを比較してコンソール表示、評価比較の対象画像を重ねて再生  
   解析結果の動画を別ファイルに保存

 ４）AI学習による射形解析モデルの学習・検証を実施する

   解析結果データを入力データとして学習（ディープラーニング）し、射形解析モデル（GRU）を作成  
   解析結果データを使って、学習済射形解析モデルを検証  

＜動作環境＞

　・PC  :Windows11公式対応PC（推奨：CPU第10世代以降、主メモリ16GB）
　・OS  ：Windows 11  
　・開発言語：Python 3.12  
　・使用AIパッケージ：ultralytics==8.4.17, torch==2.7.0  
　・コマンドインターフェース：PowerShell  


＜インストール手順＞  

 １）ZIPファイルをダウンロードして解凍する  

  [ダウンロードサイト](https://github.com/noriyuki-okochi/my-projects/tree/release)

  （※）＜＞Codeのプルダウンリストから＜HTPPS Download ZIP＞をクリックする

  １．zipファイルを"右クリック＞全て展開"で解凍する  
  ２．展開先フォルダーに”c:\Users\ユーザー名\”を指定する  
  ３．展開後のトップフォルダー（zipファイル名と同一）を"YOLO"にリネームする  
        作成されるフォルダー："c:\User\ユーザ名\YOLO"
  注）リネームしない場合は、以下"YOLO"フォルダーを"ZIPファイル名"に置き換える

 ２）pythonをMicrosoft Storeからインストールする

  ・インストールの有無、インストール済pythonのバージョン確認
     
      > python -V  

   注）Visual Studio(C:\ProgramFile(x86)\Microsoft VisualStudio)がないときは、  
     Visual Studio Community206のインストールが必要。  

   [ダウンロードサイト](https://visualstudio.microsoft.com/ja/vs/community/)  
  
  （※）インストール時に、「Python開発」にチェックを入れる

 ３）ターミナル（管理者）、またはPowerShell（管理者）でコンソールを開く

    タスクバーのスタートアイコンを右クリックメニューで選択する

  　１.アプリ実行フォルダーに移動して、セットアッププロファイルを作成する

      >cd c:\Users\ユーザー名\YOLO  
      >python ./src/setup.py $profile  

      コンソールオープン時に自動的に実行されるユーザープロファイル作成の選択あり  

    ２．セットアッププロファイルを実行する

      >./SetupKyudo.ps1  

    （注）アンチウィルスソフトのリアルタイムスキャンを停止しておく  

    （参考：プロファイルの実行内容）  
       ① ユーザー許可のプロファイル実行ポリシーを恒常的に設定する 

            > Set-ExecutionPolicy RemoteSigned  

       ② カレントのフォルダー位置をアプリの実行フォルダーに設定する  
       ③ 動画ファイルを保存するデフォルトのフォルダーを設定する  
       ④ 必要に応じて、Pythonの仮想環境を作成する  
       ⑤ アプリ実行に必要なパッケージをインストールする  

           > python -m pip install -r  requirments.txt  

＜実行手順＞

 １）ターミナル、またはPowerShellでコンソールを開く

    アプリ実行環境を構築するプロファイルを実行する
   
      > ./StartKyudo.ps1  

    （注）インストール手順３）ー１．でユーザープロファイルを作成したときは不要

 ２）helpメニューを参照して、コンソールからコマンドを入力する

    使用できるコマンド一覧をコンソールに表示する
  
     > help  

    コマンド：help, yoloAp, chart, kyudo, model  

     > <コマンド> -help  

    コマンド毎のオプション指定方法をコンソールに表示する

＜実行例＞

 １）仮想環境をアクティブにする（セットアップで仮想環境を作成したとき）

     >actvenv  

    コンソールオープン時、ユーザープロファイルの実行でアクティブになっている場合は不要

 ２）既定の実行環境変数を表示する

     >model  

    '-help'オプション指定で、環境変数の変更方法がコンソールに表示される

 ３）学習時のハイパーパラメータを変更する

     >model -hp (96, 64, 300, 0.1)  
  
    ミニバッチサイズ=64,エポック数=300,学習率の低減率=0.1に変更する

 ４）動画ファイルを生再生する

     >yoloap -raw -at 100 -fps 0.5 
  
    ファイル選択ダイアログで再生ファイルを指定する  
    再生開始フレームに100を指定(-at)  
    画像保存時のフレームレートに<再生ファイルのレートｘ0.5>を指定(-fps)  
    キーボード操作により各種再生モードの切り替え可能（'yoloap -h'でキー操作一覧を表示）

 ５）二つの動画ファイルを重ねて再生する

     >yoloap -multi '100,200'
  
    ファイル選択ダイアログで再生ファイルを二つ指定する  
    再生開始フレームを第一、第二ファイルそれぞれ100,200に指定する
  
 ６）動画ファイルをクリッピングして別ファイルに保存する

     >yoloap -clip  
  
    ファイル選択ダイアログでクリッピング対象ファイルを指定する  
    保存先ファイル名は選択ファイル名先頭に'_'を付加したファイル名となる  
    マウスドラッグによる矩形で切り取り範囲を指定  
    二番目以降の矩形でモザイク処理をする範囲を指定可能  
    '-rotate'オプションを追加指定することで、画像を９０度時計回りに回転して再生可能  
    ファイル出力開始／停止は'w'キーで操作する

 ７）動画をYOLO-poseモデルで姿勢解析し、動画に表示・再生する

     >yoloap -yolo  -kpt 1 -v8 m 
  
    ファイル選択ダイアログで解析対象ファイルを指定する  
    描画するキーポイント番号に1、解析モデルにYOLOv8mを指定  
    
      0 = ボックスと全てのキーポイントのライン（デフォルト）
      1 = 頭上から見た左右の手首-肘-肩のライン
      2 = 右側面から見た腕、胴、足のライン
      3 = 正面から見た目、両腕、胴のライン

    姿勢解析モデルは以下のオプションで選択可能  
      -v8 s  :: YOLOv8s（デフォルト）  
      -v8 m  :: YOLOv8m（精度が上がるが解析時間がかかる）
      -v26 s :: YOLO26s（最新バージョン）
      -v26 m :: YOLO26m（最新バージョン）

 ８）射形動画をプログラムロジックで射法八節姿勢解析し、動画に表示・再生する

     >yoloap -man  -eval  
  
    ファイル選択ダイアログで解析対象ファイルを指定する  
    デフォルトの骨格解析はYOLOv8s(-v8 s)  
    デフォルトの八節解析パラメータレベルは2(-level 2)  
    デフォルトのデータサンプリングは１フレーム毎、比較フレーム間隔は７フレーム(-sample 1.7)  
    八節解析の開始、節開始/完了の強制指定はキー操作('0', '1'-'9'/スペース)で行う  
    '-eval'オプションを指定すると、姿勢解析のデータを評価してスコアを表示する

 ９）８）の解析結果画像を別ファイルに、解析データをCSVファイルに保存しながら再生し、ケース名を登録する

     >yoloap -case yoshimoto_2m.0 -v8 m -level 0 -sample 1.10  
  
    骨格解析はYOLOv8m,八節解析パラメータレベルは0,データサンプリングは1.10を指定  
    動画ファイル出力開始／停止は'w'キーで操作する  
    保存先動画ファイル名は選択ファイル名先頭に'_'を付加したファイル名となる  
    CSVファイル出力開始／停止は't'キーで操作する

 １０）射形動画を学習済AI(GRU)モデルで射法八節姿勢解析し、動画に表示・再生する

     >yoloap -gru -  -sample 1.10  
  
    学習済モデル(GRU)ファイルに既定のファイル('-')を指定  
    データサンプリングに1.10を指定  
    '-case'パラメータを指定することで再生動画ファイル、解析データファイル出力を指定できる  
    '-level'パラメータを指定することで、プログラムロジック解析と併用して射法八節姿勢解析を行う  
    （最も解析精度が高い）

１１）解析データをデータベースに登録する（CSVファイルをDBにインポートする）

     >kyudo -list case_name  
 
    登録済データ（ケース名）をコンソールに表示する  
    'case'指定で詳細リスト,'case_name'は名前、メモのみ表示  
  
     >kyudo -import yoshimoto_2m.0  

    データベース登録後、解析データをプロット表示する

１２）解析結果（骨格ポイントデータ:tracking_data）をプロットする

     >chart -case yoshimoto_2m.0 -key right_wrist  
  
    右手首のフレーム間移動量（ブロック高さで正規化）と、検出精度、節の移行状況グラフを上下にプロットする

     >chart -case yoshimoto_2m.0 -key 'right_wrist,left_wrist'  
  
    右手首、左手首のフレーム間移動量（ブロック高さで正規化）のグラフを上下にプロットする  
    キーポイントを４点指定したときは、グラフを上下、左右にプロットする  
    次のコマンドでキーポイントの一覧を出力できる  
   
    >chart -list_key  

１３）解析結果（GRUモデル入力データ:kyudo_data）をプロットする

     >kyudo -case yoshimoto_2m.0 -input_key 80  
  
    入力キー番号=80で定義されたモデル入力データを上下にプロットする  
    次のコマンドで定義済の入力キーの情報一覧を出力できる
     
     >kyudo -list key  

１４）解析結果（射形評価データ:eval_data）をコンソール出力する

     >kyudo -eval 'yoshimoto_2m.9'  
  
    打ち起こし、引き分け、会、残心における矢、腕の角度、保持時間、フレームNOなどをコンソールに出力する  
    '*'指定で登録済のすべて、カンマ(,)区切りの複数ケース名指定で比較表示できる  
    指定ケース名は部分一致で登録済ケース名から検索される

１５）射形評価データを動画の再生で比較、確認する

     >yoloap -one yoshimoto_2m.0 -at 100  
     >yoloap -comp 'yoshimoto_2m.0' -at '5.10'  

    オプションに'-one'指定時はrawモード、'comp'指定時はロジック解析モードで再生する
    登録済ケース名を一つ指定して、指定フレーム番号から動画を開始、再生する  
    フレーム番号の指定を解析ステップの形式で指定可能、解析済の動作フレームから開始、再生する  
    ステップ指定形式:: <節番号>.<ステップ番号>  
    （節番号=1～8、11～18、ステップ番号=0:各節の完了移行直前,以外は特定状態.例.'5.10'大三）
    TABキーの押下で、次ステップの完了移行直前のフレームにジャンプできる

     >yoloap -comp 'yoshimoto_2m.0,yoshimoto_2m.9' -at '4.0'  

    二つのケース名を指定して、「打ち起こし完了」から動画を重ねて再生する  

    >yoloap -comp 'yoshimoto_2m.0,yoshimoto_2m.0' -at '5.10,15.10'  

    同一ケース名を指定して、甲矢、乙矢の大三から動画を重ねて再生する  

     >model -add  0.5  

    重ね画像のアルファ値を設定することで、画像のコントラストを調整する
    アルファ値は第１画像の比重(1.0未満)を示す。0.5で同等となる  

 
１６）GRUモデルの学習を実行する

     >kyudo -tarin yoshimoto_2m.0 -model kyudo2_80_modelse_8-96-3.pt  

    '-train'オプションに'list'を指定したとき、実行環境変数「登録済ケースリスト」を学習サンプルデータとする  
    「登録済ケースリスト」がスペース区切りの場合、各々を１サンプルデータとして扱い順次、追加学習を行う  
    「登録済ケースリスト」がカンマ区切りの場合、すべてを連結して１サンプルデータとして学習を行う  
    学習時のハイパーパラメータは既定の実行環境変数を参照する  
    指定モデルのファイルが存在しないときは新規の学習、存在するときは追加の学習を実行する

１７）学習済GRUモデルの予測結果を検証する  

     >kyudo -pridict yoshimoto_2m.0 -model kyudo2_80_modelse_8-96-3.pt  

    '-predict'オプションで指定したケースの解析データをサンプルデータとして、指定モデルで予測した結果と比較する

１８）データベース登録済のケース（解析データ情報）を削除、リネームする

     >kyudo -rename yoshimoto_2m.0 -to yoshimoto_2m.0_new  
     
     >kyudo -delete yoshimoto_2m.0_new

# プロジェクト名：弓道射法八節射形解析アプリケーション開発

## １．目的

弓道の射形動画の姿勢解析から、射法八節の動作を解析するAI（GRU）モデルを作成する。  
  
## ２．機能概要

### １）動画ファイルを再生する

再生中、キー押下によって以下の操作ができる  
  ・再生の一時停止／再開、終了  
  ・再生速度の変更（スロー再生、早送り）  
  ・画像（フレーム）のスキップ、巻き戻し  
  ・繰り返し再生  
  ・スクリーンへのグリッド表示、画像の部分拡大（ズームアップ。ただし画素は粗くなる）  
  ・二つの動画を重ねて再生する  

### ２）動画ファイルをクリッピングして、別ファイルに保存する

  ・別ファイル保存したい矩形領域を、マウスでドラッグして指定（平面的なクリッピング）  
  ・2番目以降の矩形領域でモザイク表示を指定  
  ・別ファイルへの書き出し開始／停止をキー操作で指定（時間的なクリッピング）  

### ３）骨格の動きをAI(YOLOモデル)で姿勢解析し、プログラムによるロジック解析および、下記4.のGRUモデルで射法八節の動作状況を判定して表示する
  
  ・動画ファイルの射形を解析して、骨格の動き、射法八節の動作状況を表示する  
  ・解析結果のデータをファイルに保存、DBへの登録、解析データのプロット表示  
  ・解析中の動画を別ファイルに保存  

### ４）射形解析モデルのAI学習・検証を実施する
  
  ・3)の解析結果データを入力データとして学習（ディープラーニング）し、射形解析モデル(GRU)を作成  
  ・3)の解析結果データを使って、学習済射形解析モデルを検証  

## ３．開発、動作環境

  ・PC  :Windows11公式対応PC（推奨：CPU第10世代以降、主メモリ16GB）  
  ・OS  ：Windows 11  
  ・操作環境：PowerShellコンソール  
  ・開発言語：Python 3.12  
  ・使用AIパッケージ：ultralytics==8.4.17, torch==2.7.0  

## ４．開発の中間結果プロファイル

### １）成果の概要

射法八節に正しく従っている弓道の射形動画をOpenCVで再生しながら、YOLOv8 poseによる姿勢解析データを入力データ
としてGRUモデルで八節の動作移行を予測するモデルを作成し、訓練データの近傍でほぼ正しく予測することができた。

### ２）モデルの概要

KyudoGRUs (  
 (face_embed): Embedding(3, 4)  
 (section_embed): Embedding(10, 8)  
 (completed_embed): Embedding(3, 4)  
 (gru): GRU(21, 64, batch_first=True)  
 (fc): Linear(in_features=64, out_features=3, bias=True)  
)  

・シングルヘッドのGRU  
・埋め込み対象：顔の向き、節番号、移行動作の完了状態  
・モデル出力（移行中/完了/開始）から遷移した節番号、移行動作の完了状態を入力シーケンスにフィードバック  

### ３）データ構造・特徴量

YOLOv8 poseのキーポイントデータから抽出した座標データをベクトル化し、normはボックスの高さで正規化した  
rw_norm;右手首をフレーム間でベクトル化（変化量）  
rl_norm:右手首 -> 左手首のベクトル（間隔）  
hr_norm:右腰 -> 右手首（間隔）  
hr_deg:右腰 -> 右手首（角度/180.0）  
body:右肩 -> 左肩のベクトル（間隔）  
face:右目 -> 左目のベクトル（間隔）  
section:節番号(0 - 9)  
completed:移行動作の完了状態（0:移行中,1:完了）  

### ４）検証結果の評価

・訓練データのラベルは移行中(0)が大半のため、ピンポイントで完了(1),開始(2)が一致することは期待できず、
正解率では評価できない。  
・射法八節に正しく従っている動画サンプルでは、射法八節の動作移行をほぼ正しく予測することができるが、
不規則な移行動作が含まれると誤った予測結果が発生するので、YOLOv8 poseのキーポイントデータからロジック
による解析を同時に行って不合理な予測結果を無効とする処理（AIとロジックのハイブリッド）が必要となる。
